# BURN-EX: Privacy-Preserving AI Energy Expenditure Tracker
**Version:** 1.0 (Hackathon Edition)  
**Target Environment:** Edge / Local Execution (Python 3.10+)  
**Core Paradigm:** Extract -> Calculate -> Infer -> Render (Zero raw-video storage)

---

## 1. Project Overview
Burn-Ex is an AI-powered system that estimates a user's physical energy expenditure (calories burned) during exercise. Unlike traditional systems that rely on static MET (Metabolic Equivalent of Task) timers, Burn-Ex uses computer vision to track temporal body-motion features—such as Range of Motion (ROM), repetition velocity, and form quality—to provide a **personalized energy expenditure range**. 

All processing is done locally on the edge, ensuring absolute privacy with zero raw-video storage.

---

## 2. System Architecture
Burn-Ex operates on a unidirectional data flow pipeline to guarantee low latency and strict privacy.

1. **Vision Layer (MediaPipe):** Captures frames, extracts 33 3D skeletal landmarks, and immediately drops the RGB frame from memory.
2. **Biomechanics Layer (OpenCV/NumPy):** Calculates joint angles, tracks velocities, and maintains the exercise state machine (Rep counting & Form validation).
3. **Feature Engineering Layer:** Aggregates temporal data (Avg ROM, Rep Rate, Duration) at the end of a workout set.
4. **ML Inference Layer (XGBoost):** Passes aggregated features to a pre-trained regression model to output an estimated energy expenditure range (kcal).
5. **Presentation Layer (OpenCV):** Renders a real-time Heads-Up Display (HUD).
